== Quality Requirements

=== Quality Tree

|===
| Karakteristik Kualitas | Skenario Uji | Pengukuran & Target
| **Ketepatan Temporal** | Pengguna menanyakan ancaman cyber tahun 2024. | 100% kutipan dan diagnosa berasal dari Laporan Tahunan 2024 (Hal. 284 dsb).

| **Robustness / Ketersediaan** | API key LLM habis atau koneksi internet terputus. | Sistem tetap menyajikan respon via *Deterministic Fallback* tanpa crash (HTTP 200).
